Autonomous Racecar

Autonomy software for lane-following and city-driving challenges in MIT Robotics: Science & Systems.

ROS 2PythonOpenCVA*

Overview

The racecar combined perception, localization, planning, and high-level behavior into one ROS 2 autonomy stack.

Autonomy stack

  • Perception for lane and environment understanding.
  • Particle-filter localization.
  • A* path planning.
  • A state machine for behavior coordination.

Challenges

The software supported both lane-following and city-driving tasks while coordinating multiple autonomy components.

Result

The completed system drove a 200-meter track lap in 54.7 seconds without a lane violation.
