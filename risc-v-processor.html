DIGITAL DESIGN · 2025

Pipelined RISC-V Processor

A four-stage processor designed with performance-oriented architectural features.

RISC-VHDLCachesArchitecture

Overview

This project focused on implementing a practical pipelined architecture and its control mechanisms.

Architecture

  • Four-stage RISC-V pipeline.
  • Instruction and data caches.
  • Branch speculation and pipeline stalling.

Performance features

  • Implemented bypassing to reduce unnecessary stalls.
  • Integrated cache behavior with pipeline control.
  • Handled control-flow changes through speculation and stalling.

Validation

Ran an MNIST inference workload on the completed processor.
